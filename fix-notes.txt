     d. exploreListingsInRadius - same bedroom comps (30 listings)

   - Total API calls: 8-10+ sequential calls
   - This explains the timeout - too many API calls in sequence
   
   - Potential fixes:
     a. Add timeout handling with user-friendly error message

     c. Reduce the number of bedroom performance calls
