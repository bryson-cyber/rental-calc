# Rental Revenue Calculator - Report Structure

This document describes the current report structure generated by the analysis.

## Overview

The analysis generates a comprehensive report with the following sections:

1. **Executive Summary** (AI-generated via Poe AI / Claude Opus)
2. **Revenue Projections**
3. **Annual Profit Calculations**
4. **Startup Costs & Break-Even**
5. **Market Intelligence Report**
6. **Competition Analysis**
7. **Export Options**

---

## 1. Executive Summary (AI-Generated)

**Source:** `server/poe-narrative.ts` → `generatePoeNarrativeReport()`

The executive summary is generated using Poe AI with Claude Opus model. It provides:

- **GO/NO-GO Decision** with confidence score (1-10)
- **Revenue-to-Rent Ratio** analysis
- **Primary Opportunity** identification
- **Key Risks** and mitigation strategies
- **Break-even Analysis**
- **First Action Recommendation**

### Prompt Structure

The AI receives:
- Property details (address, bedrooms, bathrooms, rent)
- Market data (occupancy rates, ADR, RevPAR)
- Competition data (top 5 competitors with revenue)
- Seasonality data (peak/slow months)
- Financial projections (conservative, realistic, optimistic)

### Output Format

```typescript
interface EnhancedNarrativeReport {
  executiveSummary: string;  // Main AI-generated narrative
  marketAnalysis: {
    overview: string;
    demandDrivers: string[];
    supplyAnalysis: string;
    competitivePosition: string;
  };
  revenueStrategy: {
    pricingRecommendation: string;
    seasonalStrategy: string;
    occupancyOptimization: string;
  };
  riskAssessment: {
    primaryRisks: string[];
    mitigationStrategies: string[];
    confidenceLevel: 'high' | 'medium' | 'low';
  };
  actionPlan: {
    immediate: string[];
    shortTerm: string[];
    longTerm: string[];
  };
}
```

## 2. Revenue Projections

**Source:** Calculated from AirDNA market data

| Scenario | Description |
|----------|-------------|
| **Conservative** | 25th percentile of comparable properties |
| **Realistic Target** | 50th percentile (median) of comparable properties |
| **Optimistic** | 75th percentile of comparable properties |

---

## 3. Annual Profit Calculations

**Formula:**
```
Annual Profit = Annual Revenue - (Monthly Rent × 12) - Annual Operating Expenses
```

**Operating Expenses Include:**
- Utilities ($150-300/month)
- Cleaning ($50-100/turnover)
- Supplies ($100-200/month)
- Platform fees (3-15% of revenue)
- Insurance ($100-200/month)
- Maintenance reserve (5% of revenue)

---

## 4. Startup Costs & Break-Even

**Startup Costs Range:** $10,850 - $13,850

| Category | Low | High |
|----------|-----|------|
| Furniture | $5,000 | $7,000 |
| Linens & Towels | $500 | $800 |
| Kitchen Supplies | $300 | $500 |
| Decor | $500 | $1,000 |
| Electronics | $1,000 | $1,500 |
| Photography | $200 | $500 |
| Initial Supplies | $350 | $550 |
| Contingency | $3,000 | $2,000 |

**Break-Even Calculation:**
```
Break-Even Months = Startup Costs / Monthly Net Profit
```

---

## 5. Market Intelligence Report

**Source:** AirDNA API

| Metric | Description |
|--------|-------------|
| **Avg Occupancy** | Average occupancy rate in the market |
| **Avg Daily Rate (ADR)** | Average nightly rate |
| **Active Listings** | Number of competing properties |
| **Est. RevPAR** | Revenue per available night (ADR × Occupancy) |

---

## 6. Competition Analysis

**Source:** AirDNA API → Top 5-10 similar properties

For each competitor:
- Property name/title
- Occupancy rate
- Rating (stars)
- Annual revenue estimate

- **PDF Report:** Full analysis with charts and tables
- **Excel Spreadsheet:** Raw data for custom analysis

## AI Integration Details

### Current: Poe AI with Claude Opus

**File:** `server/poe-ai.ts`

```typescript
// Configuration
const POE_API_BASE = 'https://api.poe.com/v1';
const MODEL = 'Claude-3.5-Sonnet'; // or 'Claude-Opus-4.1'

// Rate Limits
// - 500 requests/minute
// - No structured output support (JSON schema)
```

**Timeout:** 60 seconds per request

### Previous: Gemini AI (Deprecated)

**Files:** 
- `server/gemini-analyzer.ts`
- `server/gemini-analyzer-enhanced.ts`

**Issues:**
- Slow response times (2-5+ minutes)
- Frequent timeouts
- Rate limiting
