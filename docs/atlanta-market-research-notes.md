## Step 5: Map Tab - Geographic Analysis

### Map Features:
- **Metric Dropdown**: Can view by Occupancy, ADR, Revenue, etc.
- **Show Heatmap**: Toggle to display color-coded heatmap overlay
- **Min/Max Scale**: Green (high) to Red (low) color scale
- **Add Custom Pin**: Can add specific property addresses to compare

### Geographic Observations:
The map shows the Atlanta metro area with property markers. Key areas to focus on based on Market Explorer data:
- **Inman Park / Old Fourth Ward** - High RevPAR, high professional management
- **Midtown Atlanta** - Highest listing count, good occupancy
- **Virginia Highland** - Good occupancy and RevPAR growth
- **Grant Park** - Strong performer with good balance
- **Buckhead / Brookhaven** - Highest ADR but lower occupancy

## Summary: Site Navigation Flow for Browser Use Agent

### Step-by-Step Navigation:
1. **Navigate to**: https://coachinayah.com/market-charts
2. **Select City**: Click "Select Cities" dropdown → Type city name → Click on city option
3. **Wait for data**: Data loads automatically after city selection
4. **Dashboard Tab**: View Amenities %, TTM Occupancy, Property Types, Occupancy Heat Map
5. **Market Explorer Tab**: View table with 15 metrics for all submarkets
6. **Comp Data Tab**: View individual property listings with favorites, revenue, occupancy
7. **Map Tab**: View geographic distribution, toggle heatmap
8. **Charts Tab**: View seasonality charts (Metric by Month, YoY Change, Metric by Year)

### Key Data Points to Extract:
- From Dashboard: Occupancy by bedroom size
- From Market Explorer: Top submarkets by RevPAR, ADR, Occupancy
- From Comp Data: Top performing individual properties
- From Charts: Seasonality patterns, peak/off-peak months
