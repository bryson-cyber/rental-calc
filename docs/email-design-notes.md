# Deal Alert Email Design - Key Features

## Updated Design (February 2025)

### Property Card Section
- Property image placeholder (🏠 icon in navy/gold box)
- Property address with city/state
- Badges: "3 Bed · 2 Bath" (gold) + "Single Family" (gray)
- 4-stat grid: Est. Revenue/Mo (gold), Monthly Rent, Est. Profit/Mo (green), Occupancy
- Links: "📊 Full Analysis" + "🏠 View on Zillow"

### Comparable Properties Section (NEW)
- Header: "✓ Properties Nearby Already Making Money"
- Subtitle: "5 similar properties within 1 mile are averaging $3,850/mo"
- 5 comp cards showing:
  - Property title (e.g., "3BR · Charming Midtown Retreat")
  - Revenue/mo (green)
  - Occupancy %
  - "View →" link to Airbnb listing

### Insight Box
- Gold left border accent
- "Why we flagged this:" explanation with market context

### Turnkey Program Section (Navy background)
- Header: "What We Do For You (Turnkey Program)"
- Checklist of 6 services:
  1. Run the full numbers and validate the deal
  2. Reach out to the landlord and negotiate terms
  3. Set up the property from scratch
  4. Design and furnish it for maximum bookings
  5. Automate your operations so you can be hands-off
  6. Ongoing support to optimize your revenue

### CTA Section
- Primary: "Book a Call with Our Team" (gold button)
- Secondary: "Or view full property analysis" (gold link)

### Footer
- Coach Inayah branding
- Links: Analyze Properties, Turnkey Program
- Unsubscribe/Manage Preferences
