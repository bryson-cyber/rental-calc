# Market Research Master Prompt Summary

## Purpose
This prompt guides systematic identification of the best short-term rental markets and neighborhoods for Airbnb arbitrage BEFORE having a specific property. Used to research where to start looking for properties.

## Prerequisites
- Access to Coach Inayah (coachinayah.com/market-charts)
- Target city/submarket name
- Internet access for Airbnb listing analysis

## 8-Step Process

### Step 1: Market Selection & ZIP Code Verification
- Navigate to coachinayah.com/market-charts
- Select submarket from dropdown
- Check for available ZIP codes (CRITICAL: don't click "Add/Refresh ZIP Data" if ZIPs already exist)

### Step 2: Market Explorer Analysis with Glossary
- Click "Market Explorer" tab
- Open Glossary (REQUIRED) - displays definitions for 11 metrics
- Record all 11 metrics:
  1. Annual Revenue
  2. Occupancy
  3. ADR (Average Daily Rate)
  4. RevPAR (Revenue Per Available Room)
  5. Average Rating
  6. Total Reviews
  7. Listings
  8. Avg Monthly Listings
  9. Listings % Change
  10. Days Available
  11. Market Size

### Step 3: Bedroom Size Performance Analysis
- Navigate to "Comp Data" tab
- For EACH bedroom count (1BR, 2BR, 3BR, 4BR, 5BR+):
  - Filter by bedroom count
  - Sort by Revenue descending
  - Record: Average Revenue, Occupancy, ADR, Top 3 performers, # listings
- Create Bedroom Comparison Table
- Identify optimal bedroom size (highest revenue + 50%+ occupancy)

### Step 4: Favorite Top Performers
- Filter for optimal bedroom size
- Sort by Revenue descending
- Favorite top 10-15 properties (click heart icon)
- CRITICAL: Only favorite properties with Airbnb links (skip VRBO-only)
- CRITICAL: Verify each listing has recent reviews (within last 2 months)
- For each favorited property, analyze:
  - Annual Revenue, Occupancy Rate, ADR, Capacity
  - Competitive Strategy
  - Unique Selling Proposition

### Step 5: Map Analysis for Geographic Clusters
- Click "Map" tab
- Green pins = favorited properties, Red pins = regular
- Identify clusters of green pins
- Document 3 target neighborhoods with notable landmarks
- Use "Metric" dropdown to see revenue heatmap

### Step 6: Seasonality Analysis
- Click "Charts" tab
- Analyze Revenue by Month (focus on 2024-2025)
- Record peak months, low months, revenue range
- Analyze YoY Change % chart
- Analyze ADR trends

### Step 7: Visit Top Performer Airbnb Listings
- Return to Comp Data tab
- For top 5-7 favorited properties, click through to Airbnb
- Document for each:
  - Property Details (title, URL, revenue, occupancy, reviews, rating)
  - Photo Analysis (count, quality, staging)
  - Design & Vibe Breakdown (aesthetic, colors, flooring, furniture, kitchen, features)
  - Interior Quality Rating (1-10)
  - Instagram-Worthiness
  - Atmosphere
  - Competitive Edge

### Step 8: Compile Market Research Report
Create Google Doc with 8 sections:
1. Executive Summary
2. Market Overview
3. Bedroom Size Analysis
4. Geographic Analysis
5. Top Performer Analysis
6. Seasonality Insights
7. Recommendations
8. Next Steps

## Critical Rules
1. NEVER click "Add/Refresh ZIP Data" if ZIPs already appear in dropdown
2. ALWAYS filter by bedroom count BEFORE sorting
3. ALWAYS sort by Revenue DESCENDING (click header twice)
4. ONLY favorite properties with Airbnb links (skip VRBO-only)
5. ALWAYS hyperlink all Airbnb URLs in reports
6. ALWAYS click "Show Glossary" before Market Explorer analysis
7. ONLY analyze 2024-2025 seasonality data
8. Green pins = favorited properties; Red pins = regular properties

## Arbitrage Profit Calculation
- Target Monthly Rent x 12 = Annual Rent Cost
- Annual Rent Cost x 1.20 = Minimum Annual Revenue Required (for 20% profit)
- Example: $1,500/month rent = $18,000 annual rent → $21,600 minimum revenue needed
