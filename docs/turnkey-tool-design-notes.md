# Turnkey Tool Design Notes

## Fonts
- Headlines: Clean sans-serif (appears to be Inter or similar)
- Body text: Same sans-serif
- NO serif fonts like Playfair Display

## Colors
- Primary gold/amber: #C9A962 or similar warm gold
- Text: Dark gray/black
- Background: White/off-white
- Accent: Gold buttons with dark text

## Style
- Clean, minimal design
- Generous white space
- Rounded corners on cards and buttons
- Subtle shadows
- Professional, modern look

## Key Elements
- Gold CTA buttons
- White cards with subtle borders
- Clean typography hierarchy
- No gradients in headers
