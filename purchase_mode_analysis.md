# Purchase Mode Analysis - What's Missing?

## Current Purchase Mode Features ✅
1. **Mode Toggle** - Renting (Arbitrage) vs Buying (Purchase)
2. **Purchase Price Input** - With comma formatting
3. **Loan Type Presets** - Conventional (7%), DSCR (8.5%), FHA (6.5%), Cash (0%)
4. **Down Payment %** - Auto-fills based on loan type
5. **Interest Rate %** - Auto-fills based on loan type
6. **For-Sale Listings** - Zillow integration in Step 2
7. **Investor Metrics** - Cash Flow, CoC Return, Cap Rate, Tax Benefits
8. **Comparison Dashboard** - Side-by-side table with investor metrics
9. **Save for Comparison** - Save analyzed properties with metrics

## Missing Features for Purchase Mode 🔴

### Financial Analysis
1. **Closing Costs Estimate** - Typically 2-5% of purchase price (title, escrow, lender fees)
2. **Property Tax Estimate** - Based on location (varies by county)
3. **Insurance Estimate** - Homeowners insurance cost
4. **HOA Fees** - If applicable
5. **Renovation/Startup Budget** - Furnishing, repairs, setup costs
6. **Reserve Fund Recommendation** - 3-6 months of expenses

### Investment Projections
7. **5-Year Projection** - Equity buildup, appreciation, cumulative returns
8. **Break-Even Analysis** - How long until investment pays off
9. **Appreciation Estimate** - Based on market trends (3-5% annually)
10. **Rent vs Buy Comparison** - Compare arbitrage vs purchase for same property

### Due Diligence Tools
11. **Comparable Sales (Comps)** - Recent sales in the area for price validation
12. **Price Per Square Foot** - Market comparison metric
13. **Days on Market** - Indicates seller motivation
14. **Price History** - Has it been reduced? How long listed?
15. **Neighborhood Crime Data** - Safety score
16. **School Ratings** - Important for family rentals
17. **Walk Score / Transit Score** - Location desirability

### Financing Tools
18. **Mortgage Calculator** - Detailed amortization schedule
19. **DSCR Calculator** - Debt Service Coverage Ratio validation
20. **Refinance Scenario** - What if rates drop?
21. **Multiple Loan Comparison** - Compare different loan scenarios side-by-side

### Deal Analysis
22. **Offer Price Calculator** - Suggest offer based on target returns
23. **Maximum Purchase Price** - Based on desired CoC return
24. **Negotiation Points** - Based on days on market, price reductions

### Reports & Export
25. **Investment Summary PDF** - Professional report for lenders/partners
26. **Deal Analyzer Printout** - One-page summary for quick review

## Priority Recommendations (High Impact)
1. **Closing Costs + All-In Cash Needed** - Critical for knowing total investment
2. **5-Year Projection** - Shows long-term wealth building
3. **Property Tax + Insurance Estimates** - More accurate cash flow
4. **Comparable Sales** - Price validation
5. **Investment Summary PDF** - For sharing with partners/lenders
